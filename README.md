# College-Marks-Management-System
A full stack system for Mentors and Students to enter, edit and view marks.

## **Introduction**

This project focuses on College marks card generation for VTU 2022 Scheme for Core-CS Subjects. It includes a fully functioning back-end and front-end with a simple tech stack to demonstrate and learn usage of MySQL.
